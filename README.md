An entry for the make.fun competition `u-markk-st-one-line-no-deadline-met-6adc00ce` (One Line, No Deadline Met).

`main.py` (Python 3, standard library only, no network) writes one original
one-line text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default
`/output/entry.txt`) and prints it: a joke excusing a missed deadline: the calendar takes legal action and the to-do list stops answering.

The output is UTF-8 text of 107 characters (Unicode code points), within the
competition's 1–200 character limit.

## Run
